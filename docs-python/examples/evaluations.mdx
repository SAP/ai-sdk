This page showcases how to use the Evaluations SDK to benchmark LLMs, evaluate orchestration configurations, or prompts. It uses the publicly available [MedicationQA dataset](https://langtest.org/docs/pages/benchmarks/medical/medicationqa/), which consists of commonly asked consumer questions about medications. The workload computes industry-standard metrics to check the reliability of the responses generated by the LLM.

## Environment Setup

Add the following additional variables into your `.env` file to provide the AWS credentials and S3 bucket information for the evaluation job:

```env
AICORE_AWS_ACCESS_KEY_ID=<your-aws-access-key-id>
AICORE_AWS_SECRET_ACCESS_KEY=<your-aws-secret-access-key>
aws_access_key_id=<your-aws-access-key-id>
aws_secret_access_key=<your-aws-secret-access-key>
AWS_BUCKET_ID=<your-s3-bucket-id>
AWS_REGION=<your-aws-region>
```

## Setup

```python
from gen_ai_hub.evaluations import EvaluationClient
from dotenv import load_dotenv
import os

load_dotenv(override=True)
client = EvaluationClient.from_env()
```

**Note:** If you are using the default resource group, an orchestration URL is already available and will be selected automatically. If you have previously created object store secrets, the setup step below can be skipped.

## One-Time Setup: Create Secrets

```python
import json

AWS_S3_ENDPOINT = "s3-eu-central-1.amazonaws.com"

default_secret_creds = {
    "data": {}, "type": "S3", "pathPrefix": "sdkOutputFiles",
    "endpoint": AWS_S3_ENDPOINT, "bucket": os.getenv("AWS_BUCKET_ID"),
    "region": os.getenv("AWS_REGION"), "usehttps": "1",
}
input_secret_creds = {
    "data": {}, "name": "sdk-data", "type": "S3", "pathPrefix": "sdk_input_files/data",
    "endpoint": AWS_S3_ENDPOINT, "bucket": os.getenv("AWS_BUCKET_ID"),
    "region": os.getenv("AWS_REGION"), "usehttps": "1",
}

response = client.setup(
    default_secret_body=default_secret_creds,
    input_secret_body=input_secret_creds,
    replace_existing=True
)
print(json.dumps(response, indent=4, ensure_ascii=False))
```

## Define Evaluation Config

To know more about the structure and type of the parameters in any of the functions, you can call `help()` on it and see the docstring. For example, for `EvaluationConfig`:

```python
from gen_ai_hub.evaluations import EvaluationConfig
print(help(EvaluationConfig))
```

There are multiple ways to create an `EvaluationConfig` — with a prompt template (inline or reference) or an orchestration registry reference, and with multiple metric configurations in each `EvaluationConfig`.

```python
from gen_ai_hub.prompt_registry import PromptTemplateSpec, PromptTemplate
from gen_ai_hub.orchestration_v2.models.template_ref import TemplateRef, TemplateRefByID
from gen_ai_hub.evaluations import Dataset, MetricConfig, MetricRef, EvaluationConfig
from gen_ai_hub.orchestration_v2.models.llm_model_details import LLMModelDetails

evaluation_config_list = [
    EvaluationConfig(
        llm=LLMModelDetails(name="gpt-5", version="latest"),
        template=PromptTemplateSpec(
            template=[PromptTemplate(
                role="user",
                content="Provide a concise and informative response to the following consumer health question: {{?question}}"
            )]
        ),
        template_variable_mapping={"question": "topic"},
        dataset_config=Dataset("eval-data/testdata/medicalqna_dataset.csv"),
        metrics=[
            MetricConfig(
                # Retrieve the metric ID from client.get_system_supported_metrics()
                reference=MetricRef(id="<METRIC ID>"),
                variable_mapping={"reference": "ground_truth"},
            ),
        ],
    ),
    EvaluationConfig(
        # The name of an orchestration configuration registered in the Orchestration Registry.
        # Use the AI Launchpad or the Orchestration SDK to create and register a configuration,
        # then pass its registry name here.
        orchestration_registry_reference="<ORCHESTRATION REGISTRY REFERENCE>",
        template_variable_mapping={"question": "topic"},
        dataset_config=Dataset("eval-data/testdata/medicalqna_dataset.csv"),
        metrics=[
            MetricConfig(
                reference=MetricRef(id="<METRIC ID>"),
                variable_mapping={"reference": "ground_truth"},
            ),
            MetricConfig(reference=MetricRef(name="Content Filter on Input")),
        ],
    ),
    EvaluationConfig(
        llm=LLMModelDetails(name="gpt-5", version="latest"),
        template=TemplateRef(template_ref=TemplateRefByID(id="<TEMPLATE REF ID>")),
        template_variable_mapping={"question": "topic"},
        dataset_config=Dataset("eval-data/testdata/medicalqna_dataset.csv"),
        metrics=[
            MetricConfig(reference=MetricRef(name="Pointwise Instruction Following")),
        ],
    ),
]
```

## Run Evaluation

```python
evaluation_runs = client.evaluate(evaluation_config_list)

for current_run in evaluation_runs:
    print(f"id: {current_run.id}, status: {current_run.status}")
```

## Wait for Completion

```python
for current_run in evaluation_runs:
    print("Waiting for run:", current_run.id)
    current_run.wait_for_completion(timeout=3600)
```

## Debugging

To debug the evaluation job in case of failures, you can use these helper methods on the run object to get more details.

```python
import json

debug_info = current_run.get_debug_info()
print("Debug info:", debug_info)

debug_logs = current_run.get_debug_logs()
print("Logs:", json.dumps(debug_logs, indent=4, default=str))
```
