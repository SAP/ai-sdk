    Class SapOpenAiRealtimeWsExperimental

    A pre-configured OpenAI Realtime API (speech-to-speech) client for SAP AI Core.

    Only gpt-realtime is supported. Session configuration must use the GA session.update schema (output_modalities, nested audio), not the preview schema.

    Use SapOpenAiRealtimeWs.createClient to create an instance. This class is experimental and may change at any time without prior notice.
